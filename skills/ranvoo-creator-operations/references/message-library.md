# Message-library routing

Use the live company documents as wording sources and adapt them to the actual thread.

## UGC message library

Use sections for inbound creators, previous collaborators, negotiation, contract, logistics, Brief, content reminders, review, and publication.

## Dental professional message library

Use sections for individuals, clinics, sample experience, logistics, paid or commission offers, Pilot Tests, contracts, demos, links, codes, multi-platform use, and endorsements.

## Commercial creator message library

Use the relevant persona: Lifestyle, Pregnancy, Postpartum Mom, Toddler/Parenting, Family Lifestyle, maternal/child expert, or another expert. Select the correct paid, commission, barter, performance-data, pilot, package, ambassador, decline, or contract scenario.

## Drafting rules

- Write natural, warm, direct US-brand English.
- Preserve actual terms; never invent price, deliverables, rights, claims, dates, addresses, codes, links, or shipping status.
- Reference the creator’s latest message.
- Make each follow-up add new value.
- Draft respectful closure for 30-day candidates, but never send or terminate without explicit approval.
- The latest thread agreement overrides an older template.
- Present English first and add a concise Chinese explanation.
