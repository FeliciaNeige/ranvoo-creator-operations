# RANVOO 达人建联工作流

## 每日处理

1. 查看飞书邮箱中的相关线程及最新往来。
2. 按标题与邮件内容路由到 UGC、牙医或商业化红人合作。
3. 优先用邮箱，其次用账号链接，再用姓名加平台匹配表格记录。
4. 判断合作阶段、下一责任方和约定时间。
5. 生成按紧急程度排序的每日队列。
6. 为选中的达人生成回复和表格字段变更预览。
7. 得到明确确认后，才发送邮件并更新表格。
8. 在邮件线程和表格中分别验证执行结果。

## 跟进规则

- 未满 3 个完整自然日：观察。
- 至少 3 个完整自然日未回复：需要跟进，并更换信息角度。
- 至少 30 天未回复：列为终止候选，但不自动终止。
- 合同、付款、物流、内容截止日期和对方承诺时间优先于通用规则。

## 确认门槛

执行前必须展示达人、线程、合作分类、匹配记录、最终邮件、全部字段旧值与新值，以及所有不确定信息。任何实质变化都需要重新确认。
